#### Installation

To replicate and run this project follow the following steps using Windows Powershell:

```bash
winget install OpenJS.NodeJS.LTS
npm create vite@latest my-solid-app -- --template solid
cd my-solid-app
npm install
npm run
npm run build
npm run deploy
```
